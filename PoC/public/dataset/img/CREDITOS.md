# Créditos de las imágenes del dataset

Todas proceden de Wikimedia Commons, con licencia libre, y se consultaron con su API el 18-09-2026. Se han convertido a JPEG y reducido a 1024 px de ancho como máximo. Algunas también se han **recortado**, como se indica. Ninguna muestra el suceso simulado: las de eventos reales son ilustrativas y las de los bulos proceden de otros sucesos (ver `motivoBulo` en `lib/dataset`).
